Seleccion y navegacion

List group

experimental

Tarjeta con filas de contenido divididas por líneas finas: entradas de un listado (módulos, notificaciones, resultados).

Cuándo usarlo

  • Un conjunto corto de filas con avatar/icono, título y metadato, que pueden o no ser clicables.
  • Listas de selección o navegación donde cada fila lleva a un destino relacionado (p. ej. módulos de un curso).

Cuándo no

  • Datos tabulares con múltiples columnas comparables entre filas: usa Table.
  • Una jerarquía de varios niveles: usa Tree.
  • Pares término-descripción (metadatos de un solo recurso): usa Description list.

Anatomía

<div class="ro-list">
  <a class="ro-list__item ro-list__item--active" href="#">
    <span class="ro-avatar ro-avatar--sm">M0</span>
    <div style="flex:1"><div class="ro-list__title">Estado actual de AI</div><div class="ro-list__meta">Módulo 0 · Video</div></div>
  </a>
  <a class="ro-list__item" href="#">
    <span class="ro-avatar ro-avatar--sm">M1</span>
    <div style="flex:1"><div class="ro-list__title">Input &gt; Proceso &gt; Output</div><div class="ro-list__meta">Módulo 1 · Video</div></div>
  </a>
</div>
  • El contenedor (ro-list) es una tarjeta visual, no una lista semántica <ul>: si el conteo y el orden de los ítems deben anunciarse como lista, envuélvelos en <ul>/<li> y aplica un reset de list-style propio (RoUI no lo incluye por defecto).
  • Cada fila clicable es un <a> con href real; si no navega, usa un <button class="ro-list__item ro-list__item--link"> en su lugar para conservar el estado hover accesible por teclado.
  • El borde entre filas (ro-list__item + ro-list__item) depende de que las filas sean hermanas directas: no las envuelvas en un div intermedio.

API

Clases

ClaseDescripción
.ro-listContenedor de la tarjeta (borde, radio, overflow).
.ro-list__itemFila individual.
.ro-list__item--activeFila destacada como seleccionada/actual.
.ro-list__item--linkAplica el estilo hover de enlace a una fila que no es <a> (p. ej. un <button>).
.ro-list__titleTexto principal de la fila.
.ro-list__metaTexto secundario de la fila.

Tokens que consume

--ro-ink-10 --ro-radius-xl --ro-white --ro-ink-06 --ro-ink-02 --ro-secondary-soft --ro-secondary --ro-ink-50

Sin JavaScript: es CSS sobre HTML nativo.

Teclado y accesibilidad

TeclaAcción
Tab / Shift+TabRecorre las filas clicables (enlaces o botones) en orden del documento.
Enter / EspacioActiva la fila enfocada según sea <a> (Enter) o <button> (Enter/Espacio).

Contrato de accesibilidad: content-and-status

  • No hay controlador de teclado propio: la accesibilidad depende por completo de usar elementos nativos interactivos (<a>, <button>) para cada fila clicable, en vez de un <div> con onclick.
  • Si una fila combina texto y un badge de estado, el badge no debe ser la única forma de comunicar el estado: acompáñalo de texto.
  • Cuando la fila es puramente informativa (no navega ni activa nada), no la envuelvas en <a> ni <button>: usa un <div class="ro-list__item"> simple.

Do / Don't

Sí

  • Usa <a href> para filas que navegan y <button> para filas que disparan una acción in situ.
  • Reserva ro-list__item--active para una única fila a la vez (la selección o posición actual).
  • Acompaña avatar/badge con texto: no comuniques estado solo por color o iniciales.

No

  • No uses un <div> con onclick como fila clicable: rompe teclado y lector de pantalla.
  • No mezcles filas de distinto propósito (navegación y formulario) en la misma lista sin separarlas visualmente.
  • No lo uses para datos que necesitan comparación por columnas: eso es Table.

Madurez

experimental Apariencia o API sin garantías completas; puede cambiar sin aviso.

Datos y estado

Spinner

experimental

Indicador de carga indeterminado: un círculo animado con texto oculto para lectores de pantalla.

Cuándo usarlo

  • Comunicar que algo está cargando cuando no se conoce el avance real ni el tiempo restante.
  • Estados de carga breves dentro de un botón, tarjeta o zona pequeña de la interfaz.

Cuándo no

  • Cuando sí conoces el avance (%): usa Progress o Progress ring.
  • Para simular el layout final mientras carga contenido estructurado: usa Skeleton.

Anatomía

<span class="ro-spinner" role="status"><span class="ro-sr-only">Cargando…</span></span>
  • role="status" hace el anuncio de forma cortés (no interrumpe al usuario) apenas el spinner entra al DOM.
  • El nombre accesible viene del texto oculto (ro-sr-only), no de la animación visual, que no se anuncia por sí sola.
  • La animación respeta prefers-reduced-motion (se hace más lenta en vez de detenerse abruptamente).

API

Clases

ClaseDescripción
.ro-spinnerCírculo animado base (20px).
.ro-spinner--smTamaño compacto (14px).
.ro-spinner--lgTamaño grande (28px), trazo más grueso.
.ro-spinner--lightVariante clara para fondos oscuros.

Tokens que consume

--ro-radius-full --ro-ink

Sin JavaScript: es CSS sobre HTML nativo.

Teclado y accesibilidad

Contrato de accesibilidad: content-and-status

  • Un spinner indeterminado usa role="status" con texto oculto ("Cargando…") en vez de depender solo de la animación.
  • No dupliques anuncios: si el spinner vive dentro de un botón con estado is-loading, el botón ya comunica su propio estado (aria-busy o texto), evita dos role=status compitiendo.
  • Al terminar la carga, retira el spinner del DOM (o su role=status) y anuncia el resultado en el elemento correspondiente.

Do / Don't

Sí

  • Incluye siempre texto oculto ("Cargando…", "Guardando…") dentro del role=status.
  • Combina con is-loading en ro-btn (ver Button) en vez de anidar un spinner completo dentro del botón.
  • Usa el tamaño (sm/lg) proporcional al contexto donde aparece.

No

  • No reemplaces role="status" por un aria-live manual duplicado en el mismo nodo.
  • No quites el texto oculto asumiendo que el spinner es "obviamente" de carga.
  • No lo uses cuando sí tienes un valor de avance conocido: usa Progress.

Madurez

experimental Apariencia o API sin garantías completas; puede cambiar sin aviso.

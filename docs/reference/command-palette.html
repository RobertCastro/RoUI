Overlays

Command palette

experimental

Diálogo modal de acceso rápido (⌘K/Ctrl+K) que combina un combobox en línea para buscar y ejecutar comandos.

Cuándo usarlo

  • Dar acceso global a navegación y acciones frecuentes desde cualquier pantalla.
  • Permitir a usuarios avanzados operar por teclado sin recorrer menús.

Cuándo no

  • Para un autocompletar de un solo campo dentro de un formulario: usa Combobox.
  • Para confirmar o pedir un dato puntual: usa Modal.
  • Para una lista de acciones contextual anclada a un botón: usa Menu.

  • Es un diálogo modal (overlay-controller): mismo contrato de foco inicial, trap de Tab, Escape y restauración del foco que Modal y Drawer.
  • Dentro del diálogo, el campo de búsqueda y la lista son un combobox-controller en modo inline (data-ro-combobox-inline u options.inline:true): la lista siempre está visible, no abre/cierra por sí misma y no captura Escape ni el pointer exterior — eso lo maneja el overlay.
  • En modo inline, Enter ejecuta onSelect (la acción del comando) en lugar de rellenar el input.
  • Los encabezados de grupo (ro-cmdk__group) son role=presentation: agrupan visualmente pero no son opciones navegables.
  • El disparador usa data-ro-overlay-open y aria-haspopup=dialog; además, un listener global de teclado abre la paleta con ⌘K/Ctrl+K y limpia el input al abrir.

API

Clases

ClaseDescripción
.ro-cmdk-overlayCapa que cubre la página (backdrop), igual rol que ro-overlay.
.ro-cmdkPanel del diálogo de la paleta.
.ro-cmdk__searchCabecera con icono de búsqueda e input.
.ro-cmdk__listLista de resultados (listbox), scrollable.
.ro-cmdk__groupEncabezado de grupo (role=presentation).
.ro-cmdk__itemComando individual (role=option).
.ro-cmdk__emptyMensaje "sin comandos", oculto por defecto.
.ro-kbdEtiqueta de tecla (atajo) junto a un comando o en el disparador.

Atributos data

AtributoDescripción
data-ro-overlay-rootContenedor del overlay (inicia hidden).
data-ro-overlay-openEn el disparador: id de la paleta a abrir.
data-ro-cmdkMarca el panel de diálogo como paleta de comandos para inicializar el combobox inline.
data-ro-combobox-inlineActiva el modo inline del combobox-controller (alternativa a options.inline:true).

Teclado y accesibilidad

TeclaAcción
⌘K / Ctrl+KAbre la paleta desde cualquier lugar de la página y enfoca el campo.
EscapeCierra el diálogo (lo maneja el overlay, no el combobox) y restaura el foco al disparador.
ArrowDown / ArrowUpMueve la opción activa entre los comandos visibles (con wrap).
EnterEjecuta el comando activo y cierra la paleta.
Tab / Shift+TabCicla el foco dentro del diálogo (trap del overlay-controller).

Contrato de accesibilidad: combobox-calendar-command-palette

  • El foco entra al campo de búsqueda al abrir; al cerrar, vuelve al disparador (o al elemento que abrió con ⌘K).
  • El input mantiene el foco en todo momento: la opción activa solo se comunica por aria-activedescendant.
  • Al escribir se filtra la lista y se muestra ro-cmdk__empty si no hay coincidencias.
  • El fondo queda inerte mientras la paleta está abierta, igual que en Modal.

Do / Don't

Sí

  • Agrupa comandos afines con ro-cmdk__group para orientar el escaneo visual.
  • Muestra el atajo de teclado del comando con ro-kbd cuando exista.
  • Anuncia el atajo global (⌘K/Ctrl+K) cerca del disparador.

No

  • No anides otro diálogo modal dentro de la paleta.
  • No dejes que el combobox interno capture Escape: debe cerrarla el overlay para restaurar el foco correctamente.
  • No uses la paleta para un único autocompletar de formulario: usa Combobox.

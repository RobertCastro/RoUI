Combobox / Autocomplete

experimental

Campo de texto que filtra y despliega una lista de opciones (WAI-ARIA Combobox), sin robar el foco del input.

Cuándo usarlo

  • Elegir un valor de una lista larga que conviene poder filtrar escribiendo (lenguaje, país, usuario).
  • Autocompletar mientras el usuario escribe, manteniendo el foco siempre en el campo de texto.

Cuándo no

  • Para una lista corta de opciones fijas: usa un <select> nativo o Segmented.
  • Para elegir varios valores a la vez: usa Tags input.
  • Para lanzar comandos o navegar dentro de un diálogo global: usa Command palette.

Anatomía

<div class="ro-combobox" data-ro-combobox>
  <div class="ro-field">
    <svg class="ro-icon ro-icon--sm" aria-hidden="true"><use href="#ro-i-search"></use></svg>
    <input class="ro-input" id="cb-lang" role="combobox" aria-expanded="false" aria-controls="cb-lang-list" aria-autocomplete="list" aria-label="Busca un lenguaje" placeholder="Busca un lenguaje…">
  </div>
  <div class="ro-combobox__list" id="cb-lang-list" role="listbox" aria-label="Lenguajes">
    <div class="ro-combobox__option" role="option">JavaScript</div>
    <div class="ro-combobox__option" role="option">TypeScript</div>
    <div class="ro-combobox__option" role="option">Python</div>
    <div class="ro-combobox__empty" hidden>Sin coincidencias</div>
  </div>
</div>
  • El input lleva role=combobox con aria-expanded, aria-controls y (cuando hay opción activa) aria-activedescendant.
  • La lista es role=listbox oculta con [hidden] hasta que el controlador la abre; cada opción es role=option.
  • El foco nunca sale del input: la opción activa se comunica solo por aria-activedescendant, no moviendo el foco.
  • data-ro-combobox marca la raíz que envuelve campo y lista; combobox-controller la localiza por [role=combobox] y [role=listbox] dentro de ella.
  • Command palette reutiliza este mismo controlador en modo inline (data-ro-combobox-inline / options.inline), donde la lista siempre está visible y no se abre/cierra por sí misma.

API

Clases

ClaseDescripción
.ro-comboboxRaíz posicionada (relative) que ancla la lista flotante.
.ro-fieldEnvoltorio del campo de texto (icono + input).
.ro-combobox__listPanel flotante de opciones (listbox), oculto por [hidden].
.ro-combobox__optionOpción individual (role=option).
.ro-combobox__emptyMensaje de "sin coincidencias", oculto por defecto.

Atributos data

AtributoDescripción
data-ro-comboboxMarca la raíz que envuelve el campo y la lista.
data-ro-combobox-inlineModo inline (usado por Command palette): la lista siempre está visible, sin abrir/cerrar propio ni captura de Escape.
data-valueEn una opción: valor a usar en vez de su texto visible al seleccionarla.

Teclado y accesibilidad

TeclaAcción
ArrowDown / ArrowUpAbre la lista si está cerrada y mueve la opción activa (con wrap).
Home / EndCon la lista abierta, salta a la primera o última opción visible.
EnterSelecciona la opción activa: rellena el input y cierra la lista.
EscapeCierra la lista sin seleccionar (no aplica en modo inline).
Tab / Shift+TabSale del campo; no hay trap de foco.

Contrato de accesibilidad: combobox-calendar-command-palette

  • La opción activa se marca con aria-selected="true" y se referencia desde el input vía aria-activedescendant; el foco DOM permanece en el input en todo momento.
  • Al escribir se dispara onFilter; si la opción activa queda oculta por el filtro, se limpia la selección activa.
  • Un pointerdown fuera de la raíz (data-ro-combobox) cierra la lista.
  • Cada opción recibe un id autogenerado si no lo trae, para poder ser referenciada por aria-activedescendant.

Do / Don't

Sí

  • Da nombre accesible al input con aria-label o un <label> asociado.
  • Mantén el foco siempre en el input; nunca lo muevas a las opciones.
  • Muestra el estado "sin coincidencias" cuando el filtro no encuentra nada.

No

  • No dupliques el patrón para elegir varios valores: usa Tags input.
  • No captures Escape ni el pointer exterior si construyes una variante inline (rompe el contrato del diálogo contenedor).
  • No omitas aria-controls ni aria-expanded: son los que anuncian la relación input↔listbox.

Madurez

experimental Apariencia o API sin garantías completas; puede cambiar sin aviso.

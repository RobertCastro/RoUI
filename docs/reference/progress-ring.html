Datos y estado

Progress ring

experimental

Progreso determinado en formato circular, CSS-only con conic-gradient.

Cuándo usarlo

  • Mostrar un avance único y compacto (tarjeta de resumen, dashboard) donde el espacio horizontal es limitado.
  • Cuando el porcentaje es el dato principal a destacar visualmente.

Cuándo no

  • Para progreso dentro de un flujo lineal (checklist, formulario): usa Progress.
  • Para carga indeterminada sin valor conocido: usa Spinner.

Anatomía

<div class="ro-ring" style="--val:65" role="progressbar" aria-valuenow="65" aria-valuemin="0" aria-valuemax="100" aria-label="Progreso del módulo">
  <div class="ro-ring__hole" aria-hidden="true">65%</div>
</div>
  • El anillo se dibuja con conic-gradient controlado por la variable --val (0–100), sin SVG.
  • role="progressbar" y aria-valuenow/min/max van en el contenedor .ro-ring, igual que en Progress.
  • El texto dentro de .ro-ring__hole es redundante con el valor accesible del progressbar, por eso lleva aria-hidden="true"; el nombre y valor reales los da aria-label + aria-valuenow.
  • --val y aria-valuenow deben mantenerse sincronizados manualmente: son dos atributos separados.

API

Clases

ClaseDescripción
.ro-ringAnillo circular; usa la variable --val (0–100) y opcionalmente --size.
.ro-ring--inkVariante en color de tinta (ink) en vez de la lavanda de marca.
.ro-ring--lgTamaño grande (88px) con texto interior mayor.
.ro-ring__holeCírculo interior que oculta el centro del conic-gradient y aloja el texto.

Tokens que consume

--ro-secondary --ro-ink-06 --ro-white --ro-ink

Sin JavaScript: es CSS sobre HTML nativo.

Teclado y accesibilidad

Contrato de accesibilidad: content-and-status

  • Mismo contrato que Progress: role="progressbar" con aria-valuenow, aria-valuemin, aria-valuemax y nombre accesible.
  • El número visual dentro del anillo es decorativo (aria-hidden) porque duplica lo que ya anuncia el progressbar; no elimines el aria-label pensando que el texto visible basta.
  • Si el anillo representa varias métricas a la vez, usa aria-label distintos por instancia, no un texto genérico compartido.

Do / Don't

Sí

  • Sincroniza --val con aria-valuenow cada vez que actualices el progreso.
  • Usa ro-ring--lg cuando el anillo sea el elemento principal de una tarjeta de resumen.
  • Da un aria-label específico por instancia cuando haya varios anillos en la misma vista.

No

  • No dejes el texto visual como única fuente accesible del valor; el progressbar necesita sus propios atributos aria.
  • No anides otro indicador de progreso dentro del anillo.
  • No confíes solo en el color para distinguir variantes: el porcentaje visible debe bastar sin --ro-ring--ink.

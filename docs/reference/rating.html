Rating

experimental

Selector de estrellas para capturar o mostrar una puntuación dentro de un rango pequeño y fijo.

Cuándo usarlo

  • Pedir o mostrar una puntuación de satisfacción o calidad (1 a 5 estrellas, por ejemplo).
  • Cuando el rango es corto y cada opción tiene el mismo peso visual (no un valor continuo).

Cuándo no

  • Para un rango continuo o amplio de valores: usa Slider.
  • Para elegir una única opción entre etiquetas de texto: usa Segmented.

Anatomía

<div class="ro-rating" role="group" aria-label="Puntuación">
  <button class="ro-rating__star is-active" type="button" aria-label="1 estrella" aria-pressed="true"><svg class="ro-icon" aria-hidden="true"><use href="#ro-i-star"></use></svg></button>
  <button class="ro-rating__star" type="button" aria-label="2 estrellas" aria-pressed="false"><svg class="ro-icon" aria-hidden="true"><use href="#ro-i-star"></use></svg></button>
</div>
  • El contenedor es role="group" con aria-label describiendo qué se puntúa.
  • Cada estrella es un <button> con aria-pressed que refleja si esa posición (y las anteriores) están seleccionadas.
  • La clase is-active pinta la estrella con el amarillo de marca; aria-pressed es la fuente de verdad, no el color.

API

Clases

ClaseDescripción
.ro-ratingContenedor del grupo de estrellas.
.ro-rating__starBotón de una estrella individual.
.ro-rating--readonlyVariante de solo lectura (sin cursor de interacción).

Tokens que consume

--ro-ink-20 --ro-primary

Sin JavaScript: es CSS sobre HTML nativo.

Teclado y accesibilidad

TeclaAcción
Tab / Shift+TabMueve el foco entre estrellas.
Enter / EspacioSelecciona la estrella enfocada como nueva puntuación.

Contrato de accesibilidad: native-controls

  • Cada botón lleva aria-label con el valor que representa ("3 estrellas"), no solo un icono mudo.
  • aria-pressed="true" en cada estrella hasta la puntuación actual comunica el estado sin depender del color.
  • En modo solo lectura (ro-rating--readonly), usa role="img" con un aria-label del total en vez de botones interactivos.

Do / Don't

Sí

  • Usa role="group" con aria-label describiendo qué se puntúa.
  • Da a cada estrella un aria-label con su valor numérico ("3 estrellas"), no solo un icono.
  • Refleja la selección con aria-pressed, no solo con color.

No

  • No uses rating para escalas de más de 10 puntos: se vuelve difícil de escanear y de tabular.
  • No dependas solo del relleno amarillo para comunicar la puntuación a quien no distingue color.
  • No mezcles botones interactivos y de solo lectura dentro del mismo grupo.

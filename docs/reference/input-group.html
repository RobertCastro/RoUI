Input group

experimental

Agrupa un input con un prefijo y/o sufijo (texto, icono o botón) como un único control visual.

Cuándo usarlo

  • Mostrar una unidad, moneda o símbolo pegado al valor (USD, %, @, $).
  • Adjuntar una acción directamente relacionada con el campo, como un botón de buscar o enviar.

Cuándo no

  • Para incrementar/decrementar un número: usa Number input.
  • Cuando el prefijo o sufijo no aporta significado real: un input simple con Form es suficiente.

Anatomía

<label class="ro-label" for="amount">Monto</label>
<div class="ro-input-group">
  <span class="ro-input-group__addon">$</span>
  <input id="amount" placeholder="0.00" inputmode="decimal">
  <span class="ro-input-group__addon">USD</span>
</div>
  • El addon es visual: no reemplaza el <label>. Sigue asociando el input con for/id o aria-label.
  • ro-input-group__btn convierte el sufijo en un botón de acción (debe ser <button type="button">).
  • El foco visible aparece en todo el grupo (focus-within), no solo en el input interno.

API

Clases

ClaseDescripción
.ro-input-groupContenedor que agrupa addon(s) e input.
.ro-input-group__addonPrefijo o sufijo de texto/icono, no interactivo.
.ro-input-group__btnSufijo interactivo (botón de acción).
.ro-input-group__btn--accentBotón de acción con color de marca.

Tokens que consume

--ro-radius-xl --ro-focus-ring --ro-ink-10 --ro-ink-04 --ro-ink-60

Sin JavaScript: es CSS sobre HTML nativo.

Teclado y accesibilidad

TeclaAcción
Tab / Shift+TabMueve el foco entre el input y el botón addon (si existe).
Enter / EspacioActiva el botón addon enfocado.

Contrato de accesibilidad: native-controls

  • Si no hay un <label> visible fuera del grupo, da nombre accesible al input con aria-label.
  • El addon de texto (ro-input-group__addon) no es focuseable ni anunciado como control; es contexto visual.
  • El botón addon es un <button> nativo con su propio texto o aria-label si es solo icono.

Ejemplos

Usuario con prefijo
@ 
<label class="ro-label" for="handle">Usuario</label>
<div class="ro-input-group">
  <span class="ro-input-group__addon">@</span>
  <input id="handle" placeholder="usuario">
</div>
Buscar con botón
<div class="ro-input-group">
  <input aria-label="Buscar builders" placeholder="Buscar builders…">
  <button class="ro-input-group__btn" type="button">Buscar</button>
</div>
Icono como prefijo
<div class="ro-input-group">
  <span class="ro-input-group__addon"><svg class="ro-icon ro-icon--sm" aria-hidden="true"><use href="#ro-i-mail"></use></svg></span>
  <input type="email" aria-label="Correo electrónico" placeholder="tucorreo@empresa.com">
</div>

Do / Don't

Sí

  • Mantén el texto del addon corto (1-4 caracteres o un icono).
  • Usa type="button" en el botón addon para que no envíe el formulario por accidente.
  • Da nombre accesible al input (label externo o aria-label) aunque el addon sugiera el contexto.

No

  • No pongas información imprescindible solo en el addon de texto.
  • No apiles más de un botón addon: usa un input-group con un solo botón de acción.
  • No uses el addon como único indicador de error; combina con aria-invalid y ro-error-text.

Madurez

experimental Apariencia o API sin garantías completas; puede cambiar sin aviso.

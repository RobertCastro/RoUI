Datos y estado

Tag

experimental

Etiqueta removible para filtros activos, skills o selección múltiple.

Cuándo usarlo

  • Mostrar filtros activos o valores seleccionados que el usuario puede quitar uno a uno.
  • Listar skills, categorías u opciones elegidas en un formulario (combobox, tags-input).

Cuándo no

  • Para un indicador de solo lectura sin acción de quitar: usa Badge.
  • Para navegar a una sección o filtro (sin opción de remover): usa un link o Breadcrumb.

Anatomía

<span class="ro-tag">Frontend <button class="ro-tag__close" aria-label="Quitar etiqueta"><svg class="ro-icon ro-icon--xs" aria-hidden="true"><use href="#ro-i-x"></use></svg></button></span>
  • El tag en sí no es focalizable: solo el botón de cierre entra al orden de tabulación.
  • El icono del botón es aria-hidden; el nombre accesible vive en el aria-label del botón.
  • Idealmente el aria-label incluye el valor ("Quitar Frontend") cuando hay varios tags en la misma zona.

API

Clases

ClaseDescripción

.ro-tag--accentFondo de acento (lavanda suave).
.ro-tag--brandFondo de marca (secondary).
.ro-tag--outlineSolo borde, fondo transparente.
.ro-tag__closeBotón circular de quitar; requiere aria-label.

Tokens que consume

--ro-radius-full --ro-ink-06 --ro-primary-soft --ro-secondary --ro-ink-20

Sin JavaScript: es CSS sobre HTML nativo.

Teclado y accesibilidad

TeclaAcción
Tab / Shift+TabEntra y sale del botón de cierre.
Enter / EspacioQuita la etiqueta.

Contrato de accesibilidad: content-and-status

  • El botón de cierre necesita nombre accesible propio (aria-label), no basta con el icono.
  • Al quitar un tag, mueve el foco a un elemento coherente (el siguiente tag o el campo asociado) en vez de perderlo.
  • Si el grupo de tags representa una selección que cambia (p. ej. dentro de Tags input), considera anunciar el cambio con una región aria-live cercana.

Do / Don't

Sí

  • Da al botón de cierre un aria-label específico, idealmente con el valor del tag.
  • Usa tag para selección o filtros que el usuario puede deshacer.
  • Agrupa varios tags con espaciado y wrap para que no se corten en móvil.

No

  • No uses tag para navegación permanente: usa un link o Breadcrumb.
  • No quites el aria-label del botón de cierre confiando solo en el icono.
  • No pongas texto largo dentro de un tag; resúmelo o usa Badge/Alert.

Madurez

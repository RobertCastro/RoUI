Tags input

experimental

Campo que añade y quita chips (tags) a medida que el usuario escribe y confirma valores.

Cuándo usarlo

  • Capturar una lista corta de valores discretos: destinatarios, habilidades, categorías.
  • Cuando cada valor debe verse y quitarse individualmente, no solo como texto separado por comas.

Cuándo no

  • Para elegir entre opciones predefinidas de una lista larga: usa Combobox.
  • Para un solo valor de texto libre: un ro-input-box normal es más simple.

Anatomía

<div class="ro-tags-input">
  <span class="ro-tag">React <button class="ro-tag__close" type="button" aria-label="Quitar etiqueta React"><svg class="ro-icon ro-icon--xs" aria-hidden="true"><use href="#ro-i-x"></use></svg></button></span>
  <input class="ro-tags-input__field" aria-label="Añadir etiqueta" placeholder="Añade y pulsa Enter…">
</div>
  • Los chips ya confirmados usan ro-tag; cada uno lleva su propio botón ro-tag__close con aria-label específico ("Quitar etiqueta X").
  • El input de escritura (ro-tags-input__field) vive al final de la lista de chips, dentro del mismo contenedor.
  • Confirmar un valor (Enter o coma, según implementación) lo convierte en chip y limpia el input para el siguiente.

API

Clases

ClaseDescripción
.ro-tags-inputContenedor del campo (chips + input).
.ro-tags-input__fieldInput de texto donde se escribe el siguiente tag.
.ro-tagChip de un tag ya confirmado (reusa el componente Tag).
.ro-tag__closeBotón para quitar el chip.

Tokens que consume

--ro-radius-xl --ro-focus-ring --ro-secondary --ro-ink-10

Sin JavaScript: es CSS sobre HTML nativo.

Teclado y accesibilidad

TeclaAcción
EnterConfirma el texto escrito y lo convierte en chip.
Retroceso (input vacío)Quita el último chip añadido.
Tab / Shift+TabRecorre los botones de cierre de cada chip y el input.

Contrato de accesibilidad: native-controls

  • Da nombre accesible al input con aria-label ("Añadir etiqueta") o un <label> externo asociado.
  • Cada ro-tag__close necesita un aria-label que identifique qué chip se quita, no un "Quitar" genérico repetido.
  • Anuncia los cambios (chip añadido/quitado) de forma perceptible; si usas una región aria-live, mantenla discreta (polite).

Do / Don't

Sí

  • Da a cada botón de cierre un aria-label que identifique el chip concreto que quita.
  • Deja claro cómo confirmar un tag (placeholder "Añade y pulsa Enter…" o texto de ayuda).
  • Valida y evita duplicados antes de crear el chip, no después.

No

  • No uses tags-input para una lista larga de opciones predefinidas: eso es un Combobox multi-selección.
  • No dejes chips sin botón de cierre accesible por teclado.
  • No reutilices un mismo aria-label genérico ("Quitar") para todos los chips.

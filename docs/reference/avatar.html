Contenido y estructura

Avatar

experimental

Imagen o iniciales que representan a un usuario o entidad, en tamaño fijo y forma circular.

Cuándo usarlo

  • Identificar a un usuario o entidad en un header, menú, tabla o lista.
  • Mostrar varios participantes agrupados con ro-avatar-stack.

Cuándo no

  • Para un icono de acción genérico sin identidad asociada: usa Icon o un botón de solo icono.
  • Para el logotipo principal de la marca: usa una imagen normal, no este componente.

Anatomía

<span class="ro-avatar"><img src="/avatars/maria.jpg" alt="María Gómez"></span>
<span class="ro-avatar">MG</span>
  • Con imagen: el <img> lleva alt descriptivo (nombre de la persona o entidad), salvo que un nombre visible ya esté junto al avatar, en cuyo caso alt="".
  • Sin imagen: el texto de iniciales es el contenido accesible; no necesita aria-label adicional.
  • Si el avatar en sí es un control (abre un menú de cuenta), usa <button class="ro-avatar"> con aria-label propio (p. ej. "Cuenta").

API

Clases

ClaseDescripción
.ro-avatarCírculo base de 2.25rem con iniciales o imagen.
.ro-avatar--smTamaño compacto (1.625rem), útil en tablas y listas.
.ro-avatar--lgTamaño grande (3rem).
.ro-avatar-stackAgrupa varios avatares superpuestos con borde de separación.

Tokens que consume

--ro-radius-full --ro-secondary --ro-ink --ro-focus-ring --ro-white --ro-duration --ro-ease

Sin JavaScript: es CSS sobre HTML nativo.

Teclado y accesibilidad

Contrato de accesibilidad: content-and-status

  • Un avatar de solo imagen lleva alt descriptivo, o alt="" si es puramente decorativo junto a un nombre visible; nunca dejes el atributo alt fuera del <img>.
  • En ro-avatar-stack, el último elemento suele mostrar un contador ("+64"); dale un aria-label con el total real si el número no es evidente por contexto.
  • Las iniciales como fallback deben mantener contraste suficiente frente al fondo del círculo (no solo depender del color).

Ejemplos

Imagen e iniciales
RC JP AB
<span class="ro-avatar"><img src="/avatars/maria.jpg" alt="María Gómez"></span>
<span class="ro-avatar">RC</span>
<span class="ro-avatar ro-avatar--sm">JP</span>
<span class="ro-avatar ro-avatar--lg">AB</span>
Pila de avatares
A B C +64 
<div class="ro-avatar-stack">
  <span class="ro-avatar">A</span>
  <span class="ro-avatar">B</span>
  <span class="ro-avatar">C</span>
  <span class="ro-avatar" aria-label="64 personas más">+64</span>
</div>

Do / Don't

Sí

  • Usa iniciales (2 letras) como fallback consistente cuando no hay imagen.
  • Da nombre accesible al avatar cuando es un control interactivo (menú de cuenta).
  • Combina ro-avatar-stack con un contador cuando el grupo excede el espacio disponible.

No

  • No dejes un <img> sin alt ni uses alt genérico como "avatar" o "foto".
  • No uses el avatar como único indicador de identidad si el nombre no aparece en ningún lugar cercano.
  • No mezcles tamaños de avatar dentro de una misma pila.

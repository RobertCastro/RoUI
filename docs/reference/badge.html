Datos y estado

Badge

experimental

Indicador visual pequeño para estado, categoría o conteo, con una variante de punto de estado.

Cuándo usarlo

  • Etiquetar un valor con una categoría o estado breve junto a texto ("Activo", "Beta").
  • Mostrar un conteo compacto (notificaciones, resultados) con ro-badge--count.

Cuándo no

  • Para una etiqueta que el usuario puede quitar: usa Tag.
  • Para un mensaje con contexto y posible acción: usa Alert.

Anatomía

<span class="ro-badge ro-badge--soft"><span class="ro-dot ro-dot--success"></span> Activo</span>
  • El badge es un <span> inline sin rol especial: es contenido textual, no un control.
  • El ro-dot es decorativo; el significado real vive en el texto ("Activo"), nunca solo en el color.
  • Un contador que cambia dinámicamente puede usar role="status" en el propio badge para anunciarse.

Teclado y accesibilidad

Contrato de accesibilidad: content-and-status

  • Un badge que solo repite información visual con color debe llevar texto o un aria-label equivalente.
  • Un contador (badge--count) que cambia en tiempo real puede usar role="status" opcional para anunciar el nuevo valor.
  • ro-dot suelto (sin texto adyacente) necesita contexto accesible: agrégalo dentro de un elemento con texto o aria-label.

Do / Don't

Sí

  • Combina un ro-dot con texto legible para no depender solo del color.
  • Usa ro-badge--count para números breves (notificaciones, resultados).
  • Reserva el badge para información corta y no interactiva.

No

  • No conviertas un badge en botón: si es clicable, envuélvelo o usa ro-btn con estilo propio.
  • No uses solo el color del punto para transmitir el estado.
  • No metas frases largas dentro de un badge; usa Alert para eso.

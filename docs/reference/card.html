Contenido y estructura

Card

experimental

Contenedor de superficie propia que agrupa contenido relacionado, con variantes planas, oscuras, degradadas y de fila clicable.

Cuándo usarlo

  • Agrupar contenido relacionado (título, texto, acción) en una superficie con borde propio.
  • Presentar un recurso o ítem de lista como fila completa clicable.

Cuándo no

  • Para contenido que debe bloquear la interacción del resto de la página: usa Modal.
  • Para un único bloque de texto suelto sin necesidad de agrupación visual: no añadas el envoltorio.

Anatomía

<div class="ro-card">
  <div class="ro-card__header">
    <h3 class="ro-h3">Título de la tarjeta</h3>
  </div>
  <p class="ro-body">Contenido de apoyo.</p>
  <div class="ro-card__footer">
    <button class="ro-btn ro-btn--soft ro-btn--sm">Ver más</button>
  </div>
</div>
  • ro-card__header y ro-card__footer son opcionales: úsalos solo si hay acciones o metadatos que separar del cuerpo.
  • Para una tarjeta donde toda la superficie es un único destino, usa <a class="ro-card-row"> envolviendo el contenido, no un <div> con onclick.
  • El heading interno (ro-h3) debe respetar la jerarquía real de la página, no elegirse por tamaño visual.

API

Clases

ClaseDescripción
.ro-cardContenedor base con borde y superficie propia.
.ro-card--plainVariante neutra sobre fondo de página.
.ro-card--soft-yellowVariante con borde y degradado de marca.
.ro-card-darkTarjeta sólida invertida (fondo oscuro).
.ro-card__headerFila superior: título y acción alineados.
.ro-card__footerFila inferior de acciones.
.ro-card-rowFila completa clicable; aplícala sobre un <a>, no un <div>.

Tokens que consume

--ro-radius-card --ro-card-bg --ro-card-border --ro-card-fg --ro-radius-xl --ro-radius-2xl --ro-transition

Sin JavaScript: es CSS sobre HTML nativo.

Teclado y accesibilidad

TeclaAcción
EnterActiva el enlace de la tarjeta (variante ro-card-row).

Contrato de accesibilidad: content-and-status

  • Una tarjeta íntegramente clicable usa un <a> que envuelve el contenido; evita anidar otro elemento interactivo (botón, enlace) dentro de esa misma área.
  • Si la tarjeta no es clicable en su totalidad, cualquier acción interna (botón, enlace) debe tener su propio nombre accesible; no dependas del contexto visual de la tarjeta.

Do / Don't

Sí

  • Usa <a class="ro-card-row"> para una fila totalmente clicable, nunca un <div> con onclick.
  • Reserva ro-card__footer para acciones, no para texto de relleno.
  • Mantén el heading interno alineado con la jerarquía real del documento.

No

  • No anides una tarjeta clicable dentro de otro elemento interactivo (enlace o botón).
  • No uses ro-card-dark solo por estética si el contenido no necesita ese énfasis.
  • No apiles más de un enlace/botón principal ambiguo dentro de una tarjeta clicable completa.

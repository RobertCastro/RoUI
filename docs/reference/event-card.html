Marketing y comercial

Event card

experimental

Fila de evento: bloque de fecha destacado, insignias de estado, título y meta con CTA de detalle.

Cuándo usarlo

  • Listados de eventos, sesiones o webinars donde cada fila lleva a una página de detalle.
  • Cuando el día es el dato que más rápido necesita escanear quien lee la lista.

Cuándo no

  • Para una grilla de tarjetas con precio/CTA de conversión: usa Offer card.
  • Para una lista simple sin bloque de fecha propio: usa List group.

Anatomía

<a class="ro-event-card" href="#">
  <div class="ro-event-card__date">
    <div class="ro-event-card__day">27</div>
    <div class="ro-event-card__month">Lor</div>
  </div>
  <div class="ro-event-card__body">
    <div class="ro-event-card__badges">
      <span class="ro-badge ro-badge--soft">Lorem</span>
      <span class="ro-badge ro-badge--soft">Ipsum</span>
    </div>
    <h3 class="ro-event-card__title">Lorem ipsum dolor sit amet consectetur.</h3>
    <p class="ro-event-card__meta">Lorem ipsum · Dolor sit · Amet</p>
    <span class="ro-event-card__cta">Lorem ipsum <svg class="ro-icon ro-icon--xs" aria-hidden="true"><use href="#ro-i-arrow-right"></use></svg></span>
  </div>
</a>
  • Toda la fila es un único <a>: el nombre accesible sale del texto visible (fecha + insignias + título + meta + CTA).
  • ro-event-card__date es un bloque de tamaño fijo (58×58) para que la fecha quede alineada entre todas las filas de una lista, sin importar el largo del título.
  • ro-event-card__meta usa la fuente monoespaciada del sistema (--ro-font-mono), igual que otras líneas de metadatos cortos en RoUI.
  • El color del bloque de fecha (--ro-secondary-soft) es el valor por defecto; si necesitas codificar categorías por color, sobreescribe background/color de ro-event-card__date por instancia.

API

Clases

ClaseDescripción
.ro-event-cardContenedor: fila flex, borde, radio 18px, fondo blanco.
.ro-event-card__dateBloque de fecha de tamaño fijo (58×58), fondo --ro-secondary-soft.
.ro-event-card__dayNúmero de día, grande y en negrita.
.ro-event-card__monthAbreviatura corta en mayúsculas bajo el día.
.ro-event-card__bodyColumna con insignias, título, meta y CTA.
.ro-event-card__badgesFila de insignias de estado (usa ro-badge--soft).
.ro-event-card__titleTítulo del evento.
.ro-event-card__metaLínea de metadatos (fecha completa, hora, lugar) en fuente monoespaciada.
.ro-event-card__ctaTexto de la llamada a la acción, con icono de flecha.

Tokens que consume

--ro-ink-10 --ro-ink-45 --ro-ink-55 --ro-white --ro-secondary-soft --ro-font-mono --ro-shadow-sm

Sin JavaScript: es CSS sobre HTML nativo.

Teclado y accesibilidad

TeclaAcción
TabEnfoca la fila completa (es un único enlace).
EnterNavega al destino del enlace.

Contrato de accesibilidad: content-and-status

  • Es un enlace, no un botón: usa <a href> con un destino real.
  • No dupliques el enlace dentro de la fila — un único destino por fila, igual que Offer card.
  • El día/mes del bloque de fecha es decorativo-redundante con la fecha completa en ro-event-card__meta; no dependas solo del bloque de fecha para transmitir cuándo es el evento.

Do / Don't

Sí

  • Mantén el bloque de fecha a tamaño fijo para que varias filas seguidas queden alineadas.
  • Usa ro-badge--soft para el estado del evento — insignias de bajo énfasis, no compiten con el título.
  • Repite la fecha completa en ro-event-card__meta aunque ya esté el día en el bloque de fecha.

No

  • No pongas un botón u otro enlace dentro de la fila — rompe la semántica de "toda la fila es un enlace".
  • No omitas ro-event-card__meta confiando solo en el bloque de fecha: no incluye ni hora ni lugar.
  • No uses esta fila para una oferta con precio/CTA de conversión — para eso está Offer card.

Madurez

experimental Apariencia o API sin garantías completas; puede cambiar sin aviso.

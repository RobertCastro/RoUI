Fundamentos visuales

Code

experimental

Código inline, bloques de código con barra opcional, y teclas (kbd) para representar atajos de teclado.

Cuándo usarlo

  • Referenciar un comando, nombre de archivo o valor literal dentro de una frase (código inline).
  • Mostrar un fragmento de código o salida de terminal como bloque independiente.
  • Indicar una combinación de teclas o atajo de teclado (ro-kbd).

Cuándo no

  • Para prosa larga con múltiples bloques de código mezclados con markdown (artículos, lecciones): usa Prose, que ya estiliza code/pre dentro de contenido renderizado.
  • Para mostrar datos tabulares o JSON navegable de forma interactiva: considera Table u otro componente estructurado.

  • El código inline (ro-code) va sobre <code>, dentro del flujo de texto.
  • El bloque (ro-codeblock) envuelve un <pre><code> real: preserva espacios y saltos de línea tal cual, y permite navegación por teclado del lector de pantalla dentro del bloque.
  • La barra superior (ro-codeblock__bar) es opcional: muestra el lenguaje y un botón de copiar; el botón necesita aria-label porque es de solo icono.
  • ro-kbd es independiente del resto: representa una tecla individual, se repiten instancias para combinaciones (⌘ + K).

API

Clases

ClaseDescripción
.ro-codeCódigo inline: fondo tenue, fuente mono, radio pequeño.
.ro-codeblockBloque de código oscuro con scroll horizontal.
.ro-codeblock--lightVariante clara del bloque, con borde en vez de fondo oscuro.
.ro-codeblock__barBarra superior opcional: lenguaje + acción de copiar.
.ro-kbdRepresenta una tecla individual de un atajo de teclado.

Tokens que consume

--ro-font-mono --ro-text-sm --ro-ink-05 --ro-ink --ro-on-dark --ro-radius-sm --ro-radius-xl --ro-radius-md

Sin JavaScript: es CSS sobre HTML nativo.

Teclado y accesibilidad

Contrato de accesibilidad: content-and-status

  • Usa siempre <pre><code> para el bloque, nunca <div> con white-space forzado: preserva espacios y permite navegación por teclado del lector de pantalla.
  • Añade aria-label al contenedor del bloque si el código necesita contexto adicional que no está en el texto circundante (p. ej. el lenguaje, cuando no hay barra visible).
  • El botón de copiar dentro de ro-codeblock__bar es de solo icono: requiere aria-label ("Copiar código"), no basta el icono.

Do / Don't

Sí

  • Usa ro-code para nombres de archivo, comandos cortos o valores literales dentro de una frase.
  • Da aria-label al botón de copiar dentro de la barra del bloque.
  • Elige ro-codeblock--light cuando el bloque vive sobre una superficie clara y el contraste con negro puro no aporta.

No

  • No uses ro-code para bloques multilínea: usa ro-codeblock, que maneja overflow y preserva formato.
  • No quites <pre> del bloque para "simplificar" el marcado: se pierde la preservación de espacios y la navegación por teclado del lector de pantalla.
  • No uses ro-kbd para texto que no representa una tecla real.

Madurez

Fundamentos visuales

Typography

experimental

Escala de clases de texto (display, encabezados, cuerpo, eyebrow) para construir jerarquía visual consistente sin CSS ad-hoc.

Cuándo usarlo

  • Titular una página, sección o tarjeta con un peso y tamaño ya calibrados en la escala.
  • Etiquetar una sección con un eyebrow corto en mayúsculas antes de un título.
  • Dar estilo a texto de cuerpo o texto secundario/atenuado de forma consistente.

Cuándo no

  • Para prosa larga renderizada desde markdown (artículos, lecciones): usa Prose, que ya define h1–h4, listas y citas.
  • Como sustituto de la jerarquía semántica de encabezados: la clase visual no reemplaza elegir h1/h2/h3 según la estructura del documento.

Anatomía

<span class="ro-eyebrow">Cohort · Abril 2026</span>
<h1 class="ro-display">Bienvenido, Robert.</h1>
<p class="ro-body">Semana 3 de 4 · 2 módulos completados</p>
  • Las clases son puramente visuales: no cambian el elemento HTML ni su semántica. Elige la etiqueta (h1, h2, p, span) según la estructura, no según el tamaño deseado.
  • ro-display y ro-h2 usan la fuente display; ro-h3 y ro-body usan la fuente base del documento.
  • ro-muted y ro-eyebrow--ink son modificadores de color, combinables con cualquier clase de texto.

API

Clases

ClaseDescripción
.ro-displayTitular más grande, para heros y encabezados de dashboard.
.ro-h2Título de sección grande (fuente display).
.ro-h3Título de subsección o tarjeta.
.ro-bodyTexto de cuerpo por defecto.
.ro-mutedModificador: atenúa el color del texto (--ro-text-muted).
.ro-eyebrowEtiqueta corta en mayúsculas, color de marca, para preceder un título.
.ro-eyebrow--inkVariante de eyebrow en tono neutro (ink) en vez de color de marca.

Tokens que consume

--ro-font-display --ro-font-sans --ro-text-display --ro-text-4xl --ro-weight-bold --ro-weight-medium --ro-weight-normal --ro-leading-tight --ro-leading-snug --ro-leading-relaxed --ro-tracking-tight --ro-tracking-wider --ro-text-muted

Sin JavaScript: es CSS sobre HTML nativo.

Teclado y accesibilidad

Contrato de accesibilidad: content-and-status

  • Respeta una jerarquía de encabezados sin saltos (h1→h2→h3): el nivel del elemento lo decide la estructura del documento, no el tamaño visual que necesitas.
  • ro-eyebrow suele ir junto a un encabezado, no en su lugar: no lo uses como único título de una sección.
  • El contraste de ro-muted (--ro-text-muted) es menor a propósito; no lo apliques a texto que transmita información crítica o de error.

Do / Don't

Sí

  • Elige la etiqueta HTML por jerarquía semántica y la clase ro-* por el tamaño visual que necesitas; pueden no coincidir (ej. <h2 class="ro-h3">).
  • Usa ro-eyebrow para dar contexto breve antes de un título, no como reemplazo de un encabezado.
  • Reserva ro-display para un único titular por vista.

No

  • No saltes niveles de encabezado (de h1 a h3) solo porque el h2 visual no encaja en el diseño.
  • No uses ro-muted en texto de error o de advertencia: reduce el contraste que ese contenido necesita.
  • No abuses de ro-display para titulares secundarios: pierde jerarquía si se repite en la misma vista.

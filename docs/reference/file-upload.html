File upload

experimental

Dropzone para subir archivos por arrastre o por clic, con resalte visual al soltar sobre ella.

Cuándo usarlo

  • Subir uno o varios archivos (imágenes, documentos) donde arrastrar-y-soltar agiliza la tarea.
  • Cuando conviene comunicar formatos y tamaño máximo aceptados junto al control.

Cuándo no

  • Para adjuntar un solo archivo pequeño en un formulario muy compacto: un input[type=file] simple puede bastar.
  • Cuando el archivo se genera o selecciona desde el propio sistema sin necesidad de arrastre (por ejemplo, una foto de perfil ya provista): considera un flujo más directo.

Anatomía

<label class="ro-dropzone">
  <svg class="ro-icon ro-icon--lg ro-dropzone__icon" aria-hidden="true"><use href="#ro-i-upload"></use></svg>
  <div><strong>Arrastra un archivo</strong> o haz clic para subir</div>
  <div class="ro-dropzone__hint">PNG, JPG o PDF · máx 10 MB</div>
  <input type="file" hidden>
</label>
  • El <label> envuelve al input[type=file] oculto: clic en cualquier parte de la zona abre el selector nativo de archivos.
  • El estado de arrastre activo se marca con la clase is-dragover (aplicada por script al recibir dragenter).
  • El icono es decorativo (aria-hidden); el texto "Arrastra un archivo o haz clic para subir" es lo que da contexto real.

API

Clases

ClaseDescripción
.ro-dropzoneContenedor/label de la zona de arrastre.
.ro-dropzone__iconIcono decorativo dentro de la zona.
.ro-dropzone__hintTexto secundario con formatos y límites aceptados.
.is-dragoverEstado aplicado mientras se arrastra un archivo sobre la zona.

Tokens que consume

--ro-radius-xl --ro-secondary --ro-secondary-soft --ro-ink-20 --ro-ink-02

Sin JavaScript: es CSS sobre HTML nativo.

Teclado y accesibilidad

TeclaAcción
TabEnfoca la zona (a través del input[type=file] nativo).
Enter / EspacioAbre el selector de archivos del sistema operativo.

Contrato de accesibilidad: native-controls

  • Al ser un <label> sobre un input[type=file] real, hereda foco, activación por teclado y el selector nativo del sistema operativo.
  • El arrastre (drag & drop) es una mejora adicional: la zona debe seguir siendo utilizable solo con teclado vía el input nativo.
  • Comunica formatos y tamaño máximo como texto visible (ro-dropzone__hint), no solo con el atributo accept del input.

Ejemplos

Dropzone básica
<label class="ro-dropzone" style="max-width:420px">
  <svg class="ro-icon ro-icon--lg ro-dropzone__icon"><use href="#ro-i-upload"></use></svg>
  <div><strong>Arrastra un archivo</strong> o haz clic para subir</div>
  <div class="ro-dropzone__hint">PNG, JPG o PDF · máx 10 MB</div>
  <input type="file" accept=".png,.jpg,.jpeg,.pdf" hidden>
</label>
Dropzone en estado de arrastre activo
<label class="ro-dropzone is-dragover" style="max-width:420px">
  <svg class="ro-icon ro-icon--lg ro-dropzone__icon"><use href="#ro-i-upload"></use></svg>
  <div><strong>Suelta el archivo aquí</strong></div>
  <div class="ro-dropzone__hint">PNG, JPG o PDF · máx 10 MB</div>
  <input type="file" hidden>
</label>

Do / Don't

Sí

  • Indica formatos y tamaño máximo aceptados como texto visible.
  • Mantén siempre disponible el clic/teclado como alternativa al arrastre.
  • Muestra feedback claro (lista, progreso o error) después de soltar o seleccionar el archivo.

No

  • No dependas solo del arrastre: usuarios de teclado y móvil necesitan el input nativo funcional.
  • No ocultes errores de formato o tamaño; muéstralos junto a la zona con ro-error-text.
  • No uses un <div> con listeners de drag en vez de <label> + input[type=file] real.

Seleccion y navegacion

Breadcrumb

experimental

Muestra la ruta jerárquica desde el inicio hasta la página actual, con el tramo final marcado como posición activa.

Cuándo usarlo

  • Contenido anidado en varios niveles (curso › semana › módulo) donde el usuario se beneficia de subir un nivel rápido.
  • Reforzar la ubicación dentro de una jerarquía profunda, además del nav principal.

Cuándo no

  • En sitios planos de uno o dos niveles: el breadcrumb no aporta información nueva.
  • Como sustituto del nav principal: el breadcrumb muestra jerarquía, no las secciones disponibles.
  • Para pasos de un flujo (cuenta → perfil → pago): usa Stepper, que expresa progreso, no jerarquía.

Anatomía

<nav class="ro-breadcrumbs" aria-label="Ruta de navegación">
  <a href="/">Inicio</a>
  <span class="ro-breadcrumbs__sep">›</span>
  <a href="/proyectos">Mis Proyectos</a>
  <span class="ro-breadcrumbs__sep">›</span>
  <span class="ro-breadcrumbs__current" aria-current="page">Frontend</span>
</nav>
  • El contenedor es un landmark <nav> con aria-label ("Ruta de navegación" o equivalente); sin nombre se confunde con el nav principal.
  • Todos los tramos salvo el último son enlaces reales; el tramo final es texto plano (no enlace a sí mismo) con aria-current="page".
  • El separador (ro-breadcrumbs__sep) es puramente visual: no lleva rol ni se anuncia como contenido.

API

Clases

ClaseDescripción
.ro-breadcrumbsContenedor base.
.ro-breadcrumbs--monoVariante mono/mayúsculas usada en barras de contexto compactas.
.ro-breadcrumbs__sepSeparador visual entre tramos.
.ro-breadcrumbs__currentTramo final: la página actual (texto, no enlace).

Tokens que consume

--ro-text-sm --ro-ink-60 --ro-ink-40 --ro-weight-semibold --ro-font-mono --ro-tracking-wider

Sin JavaScript: es CSS sobre HTML nativo.

Teclado y accesibilidad

TeclaAcción
Tab / Shift+TabRecorre los enlaces de los tramos anteriores; el tramo actual no es enfocable por no ser interactivo.
EnterSigue el enlace del tramo enfocado.

Contrato de accesibilidad: tabs-accordion-navigation

  • Mismo patrón que Nav: landmark con nombre y aria-current="page" en el tramo activo, sin depender solo de la clase ro-breadcrumbs__current.
  • El separador no debe anunciarse como parte del contenido: no le pongas texto significativo ni aria-label.

Do / Don't

Sí

  • Da nombre al landmark con aria-label para diferenciarlo del nav principal.
  • Deja el último tramo como texto con aria-current="page", no como enlace a la propia página.
  • Ordena los tramos de más general a más específico.

No

  • No lo uses como único mecanismo de navegación: complementa al nav, no lo reemplaza.
  • No conviertas el tramo actual en un enlace clicable hacia sí mismo.
  • No abuses de rutas de un solo nivel: si no hay jerarquía, omite el breadcrumb.

Madurez

experimental Apariencia o API sin garantías completas; puede cambiar sin aviso.

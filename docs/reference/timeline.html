Contenido y estructura

Timeline

experimental

Línea de tiempo de eventos ordenados, marcada como lista para que se anuncie el número de elementos.

Cuándo usarlo

  • Mostrar el historial o avance de un proceso con eventos fechados (estado de un pedido, progreso de un cohort).
  • Resumir una secuencia de hitos pasados, en curso y futuros en una sola vista.

Cuándo no

  • Para pasos de un formulario multi-paso que el usuario debe completar en orden: usa Stepper.
  • Para una lista simple sin relación temporal entre ítems: usa List group.

Anatomía

<ol class="ro-timeline">
  <li class="ro-timeline__item ro-timeline__item--done">
    <div class="ro-timeline__time">27 abr</div>
    <div class="ro-timeline__title">Inscripción confirmada</div>
    <div class="ro-timeline__text">Te uniste al cohort de abril.</div>
  </li>
  <li class="ro-timeline__item ro-timeline__item--active">
    <div class="ro-timeline__time">Hoy</div>
    <div class="ro-timeline__title">Módulo 4 en curso</div>
    <div class="ro-timeline__text">El arte del technical brief.</div>
  </li>
  <li class="ro-timeline__item">
    <div class="ro-timeline__time">Próximo</div>
    <div class="ro-timeline__title">Sesión en vivo</div>
  </li>
</ol>
  • Usa <ol> cuando el orden cronológico es significativo (la mayoría de los casos); <ul> si el orden no aporta información.
  • El punto y la línea conectora son ::before/::after puramente decorativos: no existen como nodos del DOM, así que no necesitan aria-hidden.
  • ro-timeline__item--active y --done comunican el estado con color; el texto ("Hoy", "27 abr") es lo que realmente transmite el significado a un lector de pantalla.

API

Clases

ClaseDescripción
.ro-timelineLista base (<ol> u <ul>), sin viñetas nativas.
.ro-timeline__itemElemento de la línea de tiempo con punto y conector.
.ro-timeline__item--activeHito en curso (punto de color secundario).
.ro-timeline__item--doneHito completado (punto sólido oscuro).
.ro-timeline__timeFecha u hora del hito, en mayúsculas/monoespaciada.
.ro-timeline__titleTítulo breve del hito.
.ro-timeline__textDescripción de apoyo opcional.

Tokens que consume

--ro-ink-20 --ro-white --ro-ink-10 --ro-secondary --ro-secondary-ring --ro-ink --ro-font-mono

Sin JavaScript: es CSS sobre HTML nativo.

Teclado y accesibilidad

Contrato de accesibilidad: content-and-status

  • Al ser una lista (<ol>/<ul>), el lector de pantalla anuncia el número total de hitos y la posición de cada uno automáticamente.
  • No confíes solo en el color del punto (--active/--done) para indicar el estado; acompaña con texto explícito cuando el estado importe para entender el hito (p. ej. "Completado", "En curso").
  • Si un hito incluye una acción (enlace, botón), esta debe tener su propio nombre accesible, igual que en cualquier otro contenido.

Do / Don't

Sí

  • Usa una lista ordenada nativa (<ol>) cuando la cronología importa.
  • Incluye una fecha u hora legible por cada hito.
  • Combina color y texto para comunicar el estado de cada hito.

No

  • No uses timeline para pasos que el usuario debe completar interactivamente; eso es Stepper.
  • No dependas solo del color del punto para indicar completado/activo/pendiente.
  • No conviertas la lista en <div>s sueltos: pierdes el conteo automático de elementos.

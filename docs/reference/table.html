Datos y estado

Table

experimental

Tabla de datos tabulares con cabeceras semánticas y variantes de hover/zebra.

Cuándo usarlo

  • Mostrar filas de datos comparables con las mismas columnas (usuarios, transacciones, registros).
  • Cuando el usuario necesita escanear y comparar valores por columna.

Cuándo no

  • Para pares término-valor sueltos: usa Description list.
  • Para una lista simple de ítems sin columnas: usa List group.

Anatomía

<div class="ro-table-wrap" tabindex="0" role="region" aria-label="Tabla de builders">
  <table class="ro-table ro-table--hover">
    <thead>
      <tr>
        <th scope="col">Nombre</th>
        <th scope="col">Proyecto</th>
        <th scope="col" class="ro-table__num">Módulos</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <th scope="row" style="font-weight:inherit;text-align:left;padding:14px 16px;border-bottom:1px solid var(--ro-ink-06)">María A.</th>
        <td class="ro-muted">Edición con IA</td>
        <td class="ro-table__num">12</td>
      </tr>
    </tbody>
  </table>
</div>
  • ro-table-wrap aporta el borde, el radio y el overflow-x del contenedor.
  • Las cabeceras de columna usan th scope="col"; si la primera celda identifica la fila, usa th scope="row" en vez de td.
  • ro-table__num alinea a la derecha y usa fuente mono, pensado para columnas numéricas.
  • El th de fila no hereda el padding/borde de tbody td (la hoja de estilos solo apunta a td); replica esos estilos en línea o con una clase de utilidad si lo usas.

API

Clases

ClaseDescripción
.ro-table-wrapContenedor con borde, radio y scroll horizontal.
.ro-tableTabla base con border-collapse y tipografía compacta.
.ro-table--hoverResalta la fila bajo el cursor.
.ro-table--zebraAlterna el fondo de filas pares.
.ro-table__numAlinea a la derecha con fuente mono (columnas numéricas).
.ro-table-toolbarBarra superior con título y acciones, antes de la tabla.

Tokens que consume

--ro-radius-xl --ro-ink-10 --ro-ink-06 --ro-ink-02 --ro-font-mono

Sin JavaScript: es CSS sobre HTML nativo.

Teclado y accesibilidad

TeclaAcción
FlechasCon el contenedor de scroll enfocado (tabindex=0), desplaza la tabla horizontalmente cuando el contenido excede el ancho disponible.

Contrato de accesibilidad: content-and-status

  • th scope="col" en cabeceras de columna y scope="row" en la celda que identifica cada fila.
  • Una tabla con scroll horizontal se envuelve en un contenedor con tabindex="0" y aria-label descriptivo para que sea navegable por teclado.
  • No comuniques el estado de una celda solo con color: combina con texto o un badge con icono.

Do / Don't

Sí

  • Usa th scope="col" / scope="row" en vez de td para cabeceras.
  • Envuelve tablas anchas en un contenedor con overflow y tabindex=0 + aria-label.
  • Alinea columnas numéricas a la derecha con ro-table__num.

No

  • No comuniques estado solo con color: acompaña el badge de texto e icono/dot.
  • No uses una tabla para maquetar contenido que no es tabular.
  • No quites el borde inferior de todas las filas sin otra forma de separación visual.

Madurez

experimental Apariencia o API sin garantías completas; puede cambiar sin aviso.

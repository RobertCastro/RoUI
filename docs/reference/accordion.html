Disclosure

Accordion

experimental

Lista de secciones colapsables; cada una es un disclosure independiente y persistente.

Cuándo usarlo

  • Preguntas frecuentes u otro contenido largo que el usuario expande solo cuando lo necesita.
  • Permitir más de una sección abierta a la vez, cada una controlada por su propio encabezado.

Cuándo no

  • Para alternar entre vistas equivalentes del mismo contexto: usa Tabs.
  • Para un menú de acciones o navegación flotante que se cierra al hacer clic fuera: usa Menu o Popover.

Anatomía

<div class="ro-accordion">
  <div class="ro-accordion__item" data-ro-disclosure-root data-ro-disclosure-persistent>
    <h3 class="ro-accordion__heading">
      <button class="ro-accordion__head" id="acc-h1" data-ro-disclosure-trigger aria-expanded="true" aria-controls="acc-p1">
        ¿Qué incluye el curso?
        <svg class="ro-icon ro-icon--sm ro-accordion__chevron" aria-hidden="true"><use href="#ro-i-chevron-down"></use></svg>
      </button>
    </h3>
    <div class="ro-accordion__panel is-open" id="acc-p1" role="region" aria-labelledby="acc-h1" data-ro-disclosure-panel>40 módulos en video, recursos descargables y checkpoints por semana.</div>
  </div>
  <div class="ro-accordion__item" data-ro-disclosure-root data-ro-disclosure-persistent>
    <h3 class="ro-accordion__heading">
      <button class="ro-accordion__head" id="acc-h2" data-ro-disclosure-trigger aria-expanded="false" aria-controls="acc-p2">
        ¿Necesito experiencia previa?
        <svg class="ro-icon ro-icon--sm ro-accordion__chevron" aria-hidden="true"><use href="#ro-i-chevron-down"></use></svg>
      </button>
    </h3>
    <div class="ro-accordion__panel" id="acc-p2" role="region" aria-labelledby="acc-h2" data-ro-disclosure-panel hidden>No. Empezamos desde los fundamentos y subimos el nivel gradualmente.</div>
  </div>
</div>
  • Cada sección es su propio data-ro-disclosure-root con data-ro-disclosure-persistent: el controlador no la cierra al hacer clic fuera ni con Escape.
  • El botón va envuelto en un encabezado real (h3) para que quede en el árbol de navegación por encabezados del lector de pantalla.
  • El panel es role=region con aria-labelledby apuntando al botón; inicia con hidden salvo la sección que abre por defecto.
  • El chevron es decorativo y rota vía CSS cuando el botón tiene aria-expanded=true.

API

Clases

ClaseDescripción
.ro-accordionContenedor con borde que agrupa los items.
.ro-accordion__itemUna sección (root del disclosure).
.ro-accordion__headingElemento de encabezado real que envuelve el botón.
.ro-accordion__headBotón disparador (data-ro-disclosure-trigger).
.ro-accordion__chevronIcono que rota según aria-expanded.
.ro-accordion__panelCuerpo de la sección (data-ro-disclosure-panel).

Atributos data

AtributoDescripción
data-ro-disclosure-rootMarca el contenedor de cada sección independiente.
data-ro-disclosure-persistentEvita el cierre al hacer clic fuera o con Escape (comportamiento de accordion, distinto de menu/popover).
data-ro-disclosure-triggerEn el botón: alterna el panel asociado.
data-ro-disclosure-panelEn el panel: contenido que se muestra u oculta.

Tokens que consume

--ro-radius-xl --ro-ink-10 --ro-ink-06 --ro-text-sm --ro-weight-semibold

Primitiva

import { createDisclosureController } from "@robertcastro/roui/primitives/disclosure-controller";

Teclado y accesibilidad

TeclaAcción
Tab / Shift+TabMueve el foco entre encabezados y hacia/desde el contenido de la página.
Enter / EspacioAlterna (abre o cierra) la sección del encabezado enfocado, vía el botón nativo.

Contrato de accesibilidad: tabs-accordion-navigation

  • Es persistente (data-ro-disclosure-persistent): a diferencia de Menu y Popover, NO se cierra al hacer clic fuera ni con la tecla Escape; permanece abierta hasta que el usuario vuelve a togglear su encabezado.
  • No hay navegación por flechas entre encabezados ni role=menu: cada encabezado es un botón independiente que se alcanza con Tab.
  • Permite más de una sección abierta a la vez; el controlador no cierra las demás al abrir una nueva.

Do / Don't

Sí

  • Envuelve cada botón disparador en un encabezado real (h2-h6) acorde a la jerarquía de la página.
  • Deja que el usuario abra varias secciones a la vez si el contenido lo permite.
  • Sincroniza aria-expanded en el botón con la visibilidad real del panel.

No

  • No esperes que Escape cierre la sección: en accordion es persistente por diseño.
  • No uses accordion para alternar vistas mutuamente excluyentes del mismo contexto: eso es Tabs.
  • No quites el encabezado semántico (h3) para "ahorrar" marcado: rompe la navegación por encabezados.

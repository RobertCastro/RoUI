Datos y estado

Progress

experimental

Barra de progreso determinada (track + fill) para tareas con un avance medible.

Cuándo usarlo

  • Mostrar el avance de una tarea con un valor conocido (checklist, subida de archivo, onboarding).
  • Cuando el usuario se beneficia de ver cuánto falta, no solo que algo está cargando.

Cuándo no

  • Cuando no se conoce el avance real (carga indeterminada): usa Spinner.
  • Para mostrar el avance como número circular compacto: usa Progress ring.

Anatomía

<div class="ro-progress" role="progressbar" aria-valuenow="42" aria-valuemin="0" aria-valuemax="100" aria-label="Progreso del checklist">
  <div class="ro-progress__fill" style="width:42%"></div>
</div>
  • role="progressbar" con aria-valuenow/aria-valuemin/aria-valuemax es obligatorio; sin ellos el valor no se anuncia.
  • El ancho inline (%) del fill debe coincidir siempre con aria-valuenow.
  • Dale nombre accesible con aria-label o aria-labelledby que describa qué mide la barra.

API

Clases

ClaseDescripción
.ro-progressTrack (contenedor) de la barra.
.ro-progress__fillRelleno; su ancho inline representa el % de avance.
.ro-progress--on-darkVariante más delgada para fondos oscuros.

Tokens que consume

--ro-radius-md --ro-ink-06 --ro-secondary

Sin JavaScript: es CSS sobre HTML nativo.

Teclado y accesibilidad

Contrato de accesibilidad: content-and-status

  • Indicadores de progreso usan role="progressbar" con aria-valuenow, aria-valuemin, aria-valuemax y nombre accesible.
  • Si el valor cambia con frecuencia, evita anuncios excesivos: actualiza el DOM sin recrear el nodo con role=progressbar.
  • Para progreso indeterminado no reutilices esta barra: usa Spinner con role="status".

Ejemplos

Con badge de fracción
2/3 
<div class="ro-row" style="gap:10px;align-items:center">
  <div style="flex:1">
    <div class="ro-progress" role="progressbar" aria-valuenow="66" aria-valuemin="0" aria-valuemax="100" aria-label="Progreso del checklist">
      <div class="ro-progress__fill" style="width:66%"></div>
    </div>
  </div>
  <span class="ro-badge ro-badge--soft">2/3</span>
</div>
Variante on-dark
<div style="background:var(--ro-ink);padding:16px;border-radius:12px">
  <div class="ro-progress ro-progress--on-dark" role="progressbar" aria-valuenow="42" aria-valuemin="0" aria-valuemax="100" aria-label="Progreso de subida">
    <div class="ro-progress__fill" style="width:42%"></div>
  </div>
</div>

Do / Don't

Sí

  • Sincroniza siempre el ancho visual del fill con aria-valuenow.
  • Da un nombre accesible claro con aria-label o aria-labelledby.
  • Acompaña la barra con el valor en texto (badge, porcentaje) cuando el espacio lo permita.

No

  • No la uses para estados indeterminados; usa Spinner.
  • No omitas aria-valuenow aunque el valor inicial sea 0.
  • No animes el fill de forma que no refleje el valor real anunciado.

Madurez

experimental Apariencia o API sin garantías completas; puede cambiar sin aviso.

Datos y estado

Skeleton

experimental

Placeholder de carga con shimmer que anticipa la forma del contenido real mientras llega.

Cuándo usarlo

  • Sustituir temporalmente tarjetas, listas o texto mientras se resuelve una petición de datos.
  • Cuando conocer la forma aproximada del contenido reduce el salto de layout al terminar de cargar.

Cuándo no

  • Para una carga breve sin forma de contenido que anticipar: usa Spinner.
  • Cuando el avance es medible y relevante para el usuario: usa Progress.

Anatomía

<div class="ro-card ro-card--plain" aria-busy="true" style="width:280px">
  <div class="ro-row" style="gap:12px">
    <div class="ro-skeleton ro-skeleton--circle" style="width:40px;height:40px" aria-hidden="true"></div>
    <div style="flex:1">
      <div class="ro-skeleton ro-skeleton--title" style="width:60%" aria-hidden="true"></div>
      <div class="ro-skeleton ro-skeleton--text" style="width:90%;margin-top:8px" aria-hidden="true"></div>
    </div>
  </div>
</div>
  • aria-busy="true" va en el contenedor real que se está cargando (la tarjeta), no en cada bloque de skeleton.
  • Cada rectángulo de skeleton lleva aria-hidden="true": es ruido visual, no contenido que deba anunciarse.
  • Al llegar el contenido real, quita aria-busy y reemplaza los bloques; si hace falta anunciar el resultado, usa una región aria-live aparte.

API

Clases

ClaseDescripción
.ro-skeletonBloque base con shimmer animado.
.ro-skeleton--textLínea de texto (altura ~0.8em).
.ro-skeleton--titleLínea de título (altura ~1.4em).
.ro-skeleton--circleForma circular (avatar).

Tokens que consume

--ro-ink-06 --ro-radius-md --ro-radius-sm --ro-radius-full

Sin JavaScript: es CSS sobre HTML nativo.

Teclado y accesibilidad

Contrato de accesibilidad: content-and-status

  • El contenedor real lleva aria-busy="true"; los bloques individuales de skeleton llevan aria-hidden="true".
  • Al terminar de cargar, quita aria-busy del contenedor y anuncia el resultado si aplica (por ejemplo con una región aria-live cercana).
  • El shimmer respeta prefers-reduced-motion (se desactiva la animación).

Do / Don't

Sí

  • Pon aria-busy="true" en el contenedor real, no en cada bloque de skeleton.
  • Aproxima el tamaño de cada bloque a las dimensiones del contenido final para evitar saltos de layout.
  • Quita aria-busy en cuanto el contenido real esté disponible.

No

  • No hagas los bloques de skeleton focalizables ni les agregues texto alternativo.
  • No dejes aria-busy="true" indefinidamente tras haber cargado el contenido.
  • No lo uses para una espera brevísima sin forma que anticipar: usa Spinner.

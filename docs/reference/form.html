Formularios

Form field

experimental

Agrupa label, control, texto de ayuda y error para construir campos de formulario accesibles y consistentes.

Cuándo usarlo

  • Capturar datos del usuario: texto, selección, texto largo, booleanos.
  • Cuando un campo necesita comunicar ayuda o un error de validación junto al control.

Cuándo no

  • Para un campo de búsqueda suelto sin formulario alrededor: usa .ro-field directamente.
  • Para un campo con prefijo/sufijo visual (moneda, icono, botón): usa Input group.

Anatomía

<div>
  <label class="ro-label" for="email">Correo electrónico</label>
  <input id="email" class="ro-input-box" type="email" autocomplete="email" required aria-describedby="email-hint">
  <p id="email-hint" class="ro-hint">Usaremos este correo para avisos.</p>
</div>
  • El wrapper es un <div> simple: el sistema no impone una clase de contenedor, solo el orden label → control → ayuda/error.
  • El <label> se asocia al control por for/id; nunca sustituyas el label por un placeholder.
  • aria-describedby conecta el control con su ro-hint y/o ro-error-text (puede listar ambos ids separados por espacio).

API

Clases

ClaseDescripción

.ro-input-boxInput de texto con borde completo.
.ro-textareaÁrea de texto multilínea.
.ro-select-boxSelect nativo con borde y chevron.
.ro-fieldVariante compacta tipo pastilla (p. ej. búsqueda inline).

.ro-error-textMensaje de error bajo el control.

Tokens que consume

--ro-control-border --ro-control-bg --ro-control-fg --ro-control-focus-border --ro-focus-ring --ro-error --ro-radius-xl --ro-radius-full

Sin JavaScript: es CSS sobre HTML nativo.

Teclado y accesibilidad

TeclaAcción
Tab / Shift+TabMueve el foco entre controles del formulario.
EspacioMarca/desmarca checkbox, radio o switch enfocado.
FlechasCambia de opción dentro de un grupo de radios nativo.

Contrato de accesibilidad: native-controls

  • Todo control requiere un <label> asociado por for/id; el placeholder no es un sustituto.
  • Un campo inválido usa aria-invalid="true" en el control y aria-describedby apuntando al ro-error-text.
  • El error debe explicar cómo corregirlo, no solo señalar que existe.
  • Los switch usan un <input type="checkbox"> real; su nombre accesible viene del label que lo envuelve.

Ejemplos

Campo con error

El nombre ya está en uso.

<div>
  <label class="ro-label" for="workspace">Nombre del workspace</label>
  <input id="workspace" class="ro-input-box" aria-invalid="true" aria-describedby="workspace-error">
  <p id="workspace-error" class="ro-error-text">El nombre ya está en uso.</p>
</div>
Select y textarea

Máximo 500 caracteres.

<div>
  <label class="ro-label" for="topic">Tema</label>
  <select id="topic" class="ro-select-box"><option>Facturación</option><option>Soporte técnico</option></select>
</div>
<div>
  <label class="ro-label" for="message">Mensaje</label>
  <textarea id="message" class="ro-textarea" aria-describedby="message-hint" placeholder="Cuéntanos qué pasó…"></textarea>
  <p id="message-hint" class="ro-hint">Máximo 500 caracteres.</p>
</div>
Checkbox y switch
<label style="display:flex;align-items:center;gap:8px"><input type="checkbox" class="ro-check" checked> Acepto los términos</label>
<label class="ro-switch"><input type="checkbox" checked aria-label="Activar notificaciones"><span class="ro-switch__track"></span></label>
Campo tipo pastilla (búsqueda inline)
<div class="ro-field">
  <svg class="ro-icon ro-icon--sm" aria-hidden="true"><use href="#ro-i-search"></use></svg>
  <input class="ro-input" aria-label="Buscar" placeholder="Buscar…">
</div>

Do / Don't

Sí

  • Usa siempre un <label> real asociado por for/id, visible en el flujo del formulario.
  • Conecta ayuda y error con aria-describedby para que el lector de pantalla los anuncie.
  • Marca aria-invalid="true" solo cuando el campo tiene un error activo.

No

  • No uses el placeholder como único texto de ayuda o como reemplazo del label.
  • No muestres un error genérico ("Campo inválido"): explica qué corregir.
  • No mezcles ro-input-box y ro-field en el mismo campo; son dos estilos distintos de control.

Madurez

experimental Apariencia o API sin garantías completas; puede cambiar sin aviso.
